# Student Collaboration Hub

A React capstone starter for student study groups, shared resources, discussion posts, and task tracking.

## Stack

- React
- React Router
- JavaScript
- HTML
- CSS
- Local storage for mock persistence

## Features included

- Landing page
- Register and login flow
- Protected routes
- Dashboard summary
- Create and join study groups
- Group discussion board
- Resource sharing links
- Task and deadline tracking
- Profile page

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```
